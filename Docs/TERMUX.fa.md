# راهنمای اجرای زفیر در ترموکس اندروید (Termux)

این راهنما نحوه اجرای کلاینت **زفیر (Zephyr)** را در محیط **ترموکس (Termux)** بدون نیاز به روت توضیح می‌دهد.

---

## ۱. پیش‌نیازها

۱. برنامه **Termux** را از مارکت [F-Droid](https://f-droid.org/en/packages/com.termux/) یا گیت‌هاب رسمی آن نصب کنید (نسخه موجود در گوگل پلی قدیمی است و نباید استفاده شود).
۲. ترموکس را باز کرده و مخازن را به‌روزرسانی کنید:
   ```bash
   pkg update -y && pkg upgrade -y
   ```

---

## ۲. نصب سریع با یک دستور

دستور زیر را در محیط ترموکس کپی و اجرا نمایید:
```bash
curl -fsSL https://raw.githubusercontent.com/haliyari/zephyr/main/zephyr.sh -o zephyr.sh && chmod +x zephyr.sh && ./zephyr.sh install
```

این اسکریپت به صورت خودکار:
- معماری پردازنده گوشی شما (مثلاً `aarch64` برای گوشی‌های ۶۴ بیتی مدرن) را تشخیص می‌دهد.
- فایل باینری کامپایل‌شده اندروید را از بخش Releases گیت‌هاب دانلود و هش SHA256 آن را بررسی می‌کند.
- فایل اجرایی `zephyr` را داخل مسیر `$PREFIX/bin` قرار می‌دهد تا با نوشتن نام آن در هر جایی اجرا شود.

---

## ۳. اتصال به سرور

برای اتصال خودکار به بهترین سرور باز از ایران، دستور زیر را در ترموکس وارد کنید:
```bash
zephyr connect --auto
```

پس از چند ثانیه خروجی زیر ظاهر می‌شود:
```text
Remote Server:  🇯🇵 Japan (219.100.37.217:443)
Assigned IP:    10.246.134.128
Local Proxy:    127.0.0.1:1095 [Dual SOCKS5 & HTTP]
```

اکنون ترموکس را در پس‌زمینه باز نگه دارید.

---

## ۴. تنظیم در تلگرام و سایر برنامه‌ها

### الف) اتصال مستقیم تلگرام اندروید
۱. وارد برنامه تلگرام شوید.
۲. به مسیر **Settings** (تنظیمات) -> **Data and Storage** (داده‌ها و ذخیره‌سازی) -> **Proxy Settings** (تنظیمات پروکسی) بروید.
۳. روی **Add Proxy** بزنید و گزینه **SOCKS5** را انتخاب کنید:
   - **Server:** `127.0.0.1`
   - **Port:** `1095`
۴. تیک ذخیره را بزنید و پراکسی را فعال کنید. تلگرام بلافاصله از طریق تونل متصل می‌شود.

### ب) عبور دادن کل ترافیک گوشی (از طریق v2rayNG یا NekoBox)
اگر می‌خواهید تمام اپلیکیشن‌های گوشی از این فیلترشکن استفاده کنند:
۱. در برنامه **v2rayNG** یا **NekoBox** یک کانفیگ جدید از نوع **Socks** بسازید:
   - Address: `127.0.0.1`
   - Port: `1095`
۲. کانفیگ را روشن کرده و اتصال VPN را فعال کنید.

---

## ۵. قطع اتصال

برای قطع اتصال، وارد ترموکس شده و کلیدهای `Ctrl + C` را فشار دهید. تونل فوراً متوقف شده و پورت ۱۰۹۵ آزاد می‌گردد.
