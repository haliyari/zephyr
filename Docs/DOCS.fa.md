# راهنمای جامع زفیر (Zephyr)

یک کلاینت قدرتمند، مستقل و سبک به زبان **راست (Rust)** برای اتصال به سرورهای MS-SSTP بدون نیاز به دسترسی روت (`sudo`) و ایجاد پراکسی دوگانه محلی **SOCKS5 و HTTP CONNECT** روی پورت `127.0.0.1:1095`.

## چرا این پروژه ساخته شد؟

کلاینت‌های سنتی SSTP در لینوکس نیازمند موارد زیر هستند:
۱. دسترسی دائم `sudo` یا کاربر روت برای ساخت اینترفیس `tun0` یا `ppp0`.
۲. دستکاری جدول مسیریابی (Routing Table) و فایل `/etc/resolv.conf`.
۳. وابستگی به ابزارهایی مثل Python، Go، pppd، یا کتابخانه‌های سیستمی سنگین.

**زفیر (Zephyr)** تمام این محدودیت‌ها را برطرف کرده است:
- **بدون نیاز به sudo یا روت:** تمامی ارتباطات و پکت‌های شبکه داخل فضای کاربر (Userspace) پردازش می‌شوند.
- **بدون تغییر در تنظیمات شبکه سیستم:** هیچ تغییری در NetworkManager یا کانفیگ‌های VPN سیستم شما ایجاد نمی‌شود.
- **یک فایل باینری کامپایل‌شده سبک (~2.9 مگابایت):** بدون نیاز به هیچ پیش‌نیاز یا کتابخانه اضافه.
- **بومی‌سازی‌شده برای شبکه ایران:** مجهز به موتور شناسایی دامنه‌های مسموم‌شده (DNS Poisoning) و مسدودیت‌های IP.

## نحوه کارکرد (معماری Userspace)

این کلاینت به جای ایجاد یک کارت شبکه مجازی در سطح هسته لینوکس، از پشته شبکه **smoltcp** در سطح کاربر استفاده می‌کند:

۱. برنامه شما (مثلاً تلگرام یا مرورگر) به آدرس `127.0.0.1:1095` وصل می‌شود.
۲. کلاینت درخواست اتصال (SOCKS5 یا HTTP CONNECT) را دریافت می‌کند.
۳. پکت‌های TCP در حافظه رم شبیه‌سازی و در قالب بسته‌های خام IPv4 فرمت‌بندی می‌شوند.
۴. بسته‌ها طبق پروتکل PPP در فریم‌های داده SSTP بسته‌بندی شده و از طریق تونل امن TLS به سرور در خارج ارسال می‌گردند.

## ویژگی‌های کلیدی

- **۱۰۰٪ کد خالص راست:** بدون Go، بدون پایتون، بدون باینری‌های C.
- **پشتیبانی از هر دو پروتکل SOCKS5 و HTTP:** روی یک پورت مشترک (`1095`).
- **سرعت اجرای آنی (< ۱ میلی‌ثانیه):** کش محلی فشرده با به‌روزرسانی خودکار هر ۴ ساعت.
- **قطع تمیز و بدون ردپا:** با فشردن `Ctrl+C` در ترمینال، تونل بسته شده و پورت ۱۰۹۵ فوراً آزاد می‌شود.
- **سازگار با تمام سیستم‌ها:** لینوکس (اوبونتو، کوبونتو، آرچ، فدورا)، اندروید (ترموکس)، مک (M1/M2/M3 و اینتل) و ویندوز.

## نصب و راه‌اندازی

### نصب سریع تک‌خطی در ترموکس اندروید (Termux)

ترموکس را باز کرده و دستور زیر را اجرا کنید:
```bash
curl -fsSL https://raw.githubusercontent.com/haliyari/zephyr/main/zephyr.sh -o zephyr.sh && chmod +x zephyr.sh && ./zephyr.sh install
```

پس از اتمام نصب، برای اتصال کافیست بنویسید:
```bash
zephyr connect --auto
```

```bash
curl -fsSL https://raw.githubusercontent.com/haliyari/zephyr/main/zephyr.sh -o zephyr.sh && chmod +x zephyr.sh && ./zephyr.sh install
```

## تنظیم پراکسی در برنامه‌ها

هنگامی که پیام `Local Proxy: 127.0.0.1:1095` در ترمینال نمایش داده شد:

### تلگرام
- وارد بخش **Settings** -> **Advanced** -> **Connection type** -> **Use custom proxy** شوید.
- گزینه **SOCKS5** را انتخاب کنید:
  - **Hostname:** `127.0.0.1`
  - **Port:** `1095`
  - نام کاربری و رمزعبور را خالی بگذارید.

### مرورگر فایرفاکس (Firefox)
- در بخش تنظیمات شبکه (Network Settings)، گزینه **Manual proxy configuration** را انتخاب کنید.
- در بخش **SOCKS Host** مقدار `127.0.0.1` و پورت `1095` را وارد کرده و تیک گزینه *Proxy DNS when using SOCKS v5* را فعال نمایید.

## دور زدن فیلترینگ و آلودگی DNS در ایران

در شبکه ایران، بسیاری از دامنه‌های داینامیک (`*.opengw.net`) به آی‌پی‌های صفحه پیوندها یا آدرس‌های نامعتبر مثل `10.10.34.34` مسموم (Poison) می‌شوند.

موتور اختصاصی زفیر:
۱. همزمان آی‌پی مستقیم سرور و دامنه DDNS را بررسی می‌کند.
۲. پاسخ‌های مسموم‌شده DNS را شناسایی و حذف می‌کند.
۳. مستقیماً به آی‌پی تمیز و فیلترنشده متصل شده و نام دامنه را در هدر امن TLS SNI ارسال می‌کند تا فایروال متوجه اتصال نشود.
